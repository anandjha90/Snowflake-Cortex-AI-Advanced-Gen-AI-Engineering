# Snowflake-Cortex-AI-Advanced-Gen-AI-Engineering
This course focuses on building AI solutions inside Snowflake using Cortex AI, for practitioners who already work as Snowflake Data Engineers or Analysts.
It follows the ADLC/SDLC 2.0 framework throughout — mapping each AI-specific skill back to familiar software-delivery phases (requirements, design, build, test, deploy, monitor) so the material connects to how these learners already think about delivery.

# Outcome Statement
On completing this course, a learner will be able to:
•  Design end-to-end agentic AI and RAG solutions on Snowflake using Cortex Agents, Cortex Search, and Cortex Analyst
•  Architect and evaluate advanced retrieval systems, including vector, graph, and hybrid Graph RAG patterns
•  Build, orchestrate, and govern multi-agent systems with MCP tool integration secured through Snowflake's managed MCP server
•  Apply responsible AI, governance, and DevSecOps practices using Snowflake Horizon, masking, and row access policies
•  Establish testing, observability, and monitoring practices that bring AI solutions to production and customer-ready delivery

# Prerequisites : Learners enrolling in this course must have:
•  Prior experience as a Snowflake Data Engineer or Data Analyst — hands-on with warehouses, SQL, RBAC, and basic Snowpark
•  Working knowledge of Snowflake's security model (roles, masking policies, row access policies)
•  Basic familiarity with generative AI / LLM concepts (prompting, embeddings)
•  Comfort with Python and API-based integration patterns

# Helpful but not mandatory:
•  Completion of an L2 Snowflake data engineering course, or equivalent applied Gen AI exposure
•  Prior hands-on exposure to Snowflake Cortex AI or Cortex Search
•  Experience with an agent framework or an MCP client (e.g., Claude, Cursor)

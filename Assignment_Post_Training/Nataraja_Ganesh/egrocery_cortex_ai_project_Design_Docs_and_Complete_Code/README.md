**Project Title:**
		Intelligent Customer Support Agent for E-Grocery using Streamlit and Snowflake Cortex

**Background & Context:**
	  Our online grocery platform serves thousands of customers daily, handling high-frequency orders of perishable and non-perishable goods. Customer satisfaction 
heavily relies on rapid issue resolution. Currently, support teams are overwhelmed by repetitive queries regarding order mistakes, missing items, product quality, and 
refund statuses.
	  By leveraging Snowflake's data platform, we can securely access real-time inventory, customer order histories, and feedback logs. Using Snowflake Cortex AI and 
Streamlit in Snowflake (SiS), we aim to build an autonomous, data-aware AI Support Agent to handle tier-1 customer interactions directly inside our data ecosystem.
